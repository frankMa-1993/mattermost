## 一、认证方式

### 1. Session Token（会话令牌）

- 登录成功后，响应头返回 `Token` 字段
- 后续请求通过 `Authorization: Bearer <token>` 或 `Cookie: MMAUTHTOKEN=<token>` 携带

### 2. Personal Access Token（个人访问令牌）

- 使用方式同 Session Token，通过 `Authorization: Bearer <personal_token>` 携带
- 不会过期，直到被手动撤销

### 3. WebSocket 认证

- 连接 `/api/v4/websocket` 端点
- 通过标准 Cookie/Header认证，或发送认证挑战:

```json
{
  "seq": 1,
  "action": "authentication_challenge",
  "data": { "token": "mattermosttokengoeshere" }
}
```

## 二、错误处理

所有错误返回统一JSON格式:

```json
{
  "id": "the.error.id",
  "message": "Something went wrong",
  "request_id": "",
  "status_code": 0,
  "is_oauth": false
}
```

### HTTP 状态码说明

| 状态码 | 含义                                   |
| ------ | -------------------------------------- |
| 400    | Bad Request - 请求参数无效或缺失       |
| 401    | Unauthorized - 未提供访问令牌          |
| 403    | Forbidden - 无权限访问该资源           |
| 404    | Not Found - 资源不存在                 |
| 409    | Conflict - 请求与当前资源状态冲突      |
| 413    | Too Large - 内容过大                   |
| 429    | Too Many Requests - 超出速率限制       |
| 500    | Internal Server Error - 服务器内部错误 |
| 501    | Not Implemented - 功能未启用           |
| 502    | Bad Gateway - 网关错误                 |

### 速率限制

响应头中包含:

- `X-Ratelimit-Limit`: 每秒最大请求数
- `X-Ratelimit-Remaining`: 当前窗口剩余请求数
- `X-Ratelimit-Reset`: 速率限制重置的剩余秒数

## 三、用户认证接口

### 3.1 用户登录

| 项目             | 说明                         |
| ---------------- | ---------------------------- |
| **路径**   | `POST /api/v4/users/login` |
| **权限**   | 无需权限                     |
| **请求体** | JSON                         |

```json
{
  "login_id": "someone@nowhere.com",  // string, 邮箱/用户名/LDAP ID
  "password": "thisisabadpassword",    // string, 密码
  "token": "",                         // string, MFA令牌（可选）
  "device_id": "",                     // string, 设备ID（可选）
  "ldap_only": false                   // boolean, 是否仅LDAP（可选）
}
```

**响应**: `201` 返回 User 对象，响应头包含 `Token` 字段

---

### 3.2 用户登出

| 项目           | 说明                          |
| -------------- | ----------------------------- |
| **路径** | `POST /api/v4/users/logout` |
| **权限** | 需要活跃会话                  |

**响应**: `201` 返回 StatusOK

---

### 3.3 创建用户

| 项目                | 说明                                                 |
| ------------------- | ---------------------------------------------------- |
| **路径**      | `POST /api/v4/users`                               |
| **权限**      | 开放服务器上无需权限；LDAP/SAML需要AuthToken         |
| **Query参数** | `t` (邀请令牌ID, 可选), `iid` (邀请链接ID, 可选) |

```json
{
  "email": "user@example.com",          // string, 必填
  "username": "john_doe",               // string, 必填
  "password": "securepassword",         // string, 邮箱登录必填
  "first_name": "John",                 // string
  "last_name": "Doe",                   // string
  "nickname": "Johnny",                 // string
  "position": "Developer",             // string
  "auth_service": "email",             // string: email/gitlab/ldap/saml/office365/google
  "auth_data": "",                      // string, 认证数据
  "locale": "zh",                       // string
  "timezone": { "automaticTimezone": "", "manualTimezone": "", "useAutomaticTimezone": "true" },
  "notify_props": {}                    // UserNotifyProps对象
}
```

**响应**: `201` 返回 User 对象

---

### 3.4 获取用户列表

| 项目                | 说明                  |
| ------------------- | --------------------- |
| **路径**      | `GET /api/v4/users` |
| **权限**      | 需要活跃会话          |
| **Query参数** |                       |

| 参数           | 类型    | 默认值 | 说明              |
| -------------- | ------- | ------ | ----------------- |
| page           | integer | 0      | 页码              |
| per_page       | integer | 60     | 每页数量(最大200) |
| in_team        | string  |        | 按团队筛选        |
| in_channel     | string  |        | 按频道筛选        |
| not_in_channel | string  |        | 排除频道中的用户  |
| sort           | string  |        | 排序方式          |

**响应**: `200` 返回 User[]

---

### 3.5 获取单个用户

| 项目           | 说明                            |
| -------------- | ------------------------------- |
| **路径** | `GET /api/v4/users/{user_id}` |
| **权限** | 需要活跃会话                    |

> `user_id` 可使用 `me` 表示当前用户

**响应**: `200` 返回 User 对象

  "position": "", "locale": "", "timezone": {}, "notify_props": {}

**响应**: `200` 返回 User 对象

| **权限** | 需要是本人或 `edit_other_users`     |

仅提供需要更新的字段，未提供的字段不会被修改。

### 3.8 停用用户

### 3.9 搜索用户

| 项目           | 说明                                      |
| -------------- | ----------------------------------------- |
| **路径** | `POST /api/v4/users/search`             |
| **权限** | 需要 `read_channel` 和/或 `view_team` |

```json
{
  "term": "john",                  // string, 必填, 搜索关键词
  "team_id": "",                   // string, 限定团队
  "in_channel_id": "",             // string, 限定频道
  "not_in_channel_id": "",         // string, 排除频道
  "not_in_team_id": "",            // string, 排除团队
  "allow_inactive": false,         // boolean, 包含已停用用户
  "without_team": false,           // boolean, 无团队用户
  "limit": 100                     // integer, 最大返回数
}
```

**响应**: `200` 返回 User[]

## 六、消息(Post)接口

### 6.1 创建消息

| 项目                | 说明                                       |
| ------------------- | ------------------------------------------ |
| **路径**      | `POST /api/v4/posts`                     |
| **权限**      | `create_post`                            |
| **Query参数** | `set_online` (boolean, 是否设置在线状态) |

```json
{
  "channel_id": "channel_id",     // string, 必填
  "message": "Hello World!",      // string, 必填, 支持Markdown
  "root_id": "",                  // string, 回复的根帖子ID(评论)
  "file_ids": ["file1", "file2"], // string[], 附件文件ID(最多5个)

      "priority": "important",    // "", "important", "urgent"
      "requested_ack": true       // boolean, 请求确认
    }
  }
}
```

**响应**: `201` 返回 Post 对象

- `201`: 上传完成，返回 FileInfo

#### 7.2.3 查询上传会话

| 项目           | 说明                                |

## 十四、分页约定

- 所有分页接口使用 `page` (从0开始) 和 `per_page` 参数

- 默认值: **60**
- 部分接口支持 `include_total_count` 返回总数
