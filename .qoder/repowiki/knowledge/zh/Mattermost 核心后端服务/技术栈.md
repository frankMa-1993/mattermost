- **Web 框架**：`gorilla/mux` 用于 REST API 路由，`gorilla/websocket` 处理实时通信。
- **数据存储**：`sqlstore` 基于 `lib/pq` (PostgreSQL) 和 `go-sql-driver/mysql` (MySQL)；使用 `mattermost/squirrel` 构建 SQL 查询。
- **缓存与搜索**：集成 `redis/rueidis` 进行分布式缓存；支持 `elastic/go-elasticsearch` 和 `opensearch-project/opensearch-go` 作为搜索引擎后端。
- **云存储**：通过 `minio/minio-go` (S3 兼容) 和 `azure-sdk-for-go` 实现文件存储抽象。
